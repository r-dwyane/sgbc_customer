# Samgyeop Grill Box Cebu

**E-Commerce Website**  
_December 2024 – March 2025_

## Overview
A web platform built for Samgyeop Grill Box Cebu—a Korean food delivery service. Customers can customize meals, validate delivery areas, receive real-time SMS order confirmations, and interact with Samgy AI, a built-in chatbot assistant. An admin dashboard handles orders, feedback, and promotions.

## Features
- **Meal Customization**  
  Choose protein, sides, sauces, and add-ons  
- **Delivery Area Check**  
  Enter address to confirm service availability  
- **SMS Confirmation**  
  Automated SMS sent when order is placed or updated  
- **Chatbot Assistant (Samgy AI)**  
  AI chat for menu help, order status, and FAQs  
- **Admin Dashboard**  
  - View and update orders  
  - Manage customer feedback  
  - Create and run promotions  

## Tech Stack
- **Frontend**  
  - HTML5, CSS3, React  
- **Backend & Database**  
  - Firebase Firestore  
  - Firebase Authentication  
  - Firebase Cloud Storage
- **Chatbot**  
  - Gemini Pro Flash Model 1.5  
  - JavaScript rules with fallback logic  
- **UI/UX**  
  - Designed in Figma
